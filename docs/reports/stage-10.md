## Найдено на этапе релиза
1. **`secrets.uc` не попадал в git** (правило `.gitignore` «всё со словом secret») — первый релиз был нерабочим; модуль переименован
   в `keystore.uc`, в CI добавлена проверка, что все импортируемые модули есть в репозитории.
2. Роутеры, настроенные до появления флага `setup_done`, при обновлении попадали в «продолжение мастера» → v1.0.1.
3. **Секция-исключение podkop (этап 6) делала доступ к API/GitHub зависимым от DNS sing-box**: на r2 (нестабильный DNS sing-box)
   служба потеряла GitHub и API и отстала на одну ревизию. Исправлено в v1.0.2: хосты API/GitHub резолвятся напрямую через публичные
   DNS и соединение идёт на реальный IP (`curl --resolve`) — он не попадает в fake-IP-набор podkop, т.е. идёт мимо туннеля при любых
   списках клиента; секция-исключение удалена со всех роутеров.
4. После sysupgrade в сохранённом `/etc/config/dhcp` остаётся перенаправление DNS podkop → без podkop у роутера нет DNS (особенность
   podkop; в README — останавливать podkop перед прошивкой).

## Не выполнено / ограничения
- Цель «до 60 КБ на флеше» не достигнута: пакет 52 КБ, но на ubifs файлы занимают ~200 КБ (0,16% от 128 МБ). Можно уменьшить
  склейкой модулей ucode в один файл и JS-вкладок — не делалось.
- Зависимость `ucode-mod-digest` (65 КБ) — для SHA-256/HMAC (uencrypt даёт только AES-CBC).
