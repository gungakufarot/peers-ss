# Этап 8 — ссылки и `--join`

Код: `invite.uc` (создание/отзыв/список/захват/возврат), `peers-ss wizard` (режим Б), `peers-ss invite …`, `peers-ss uninstall`, `install.sh --join`.

## Проверки
| Проверка | Результат |
| --- | --- |
| Ссылка регистрирует следующий роутер (VM router4, после `uninstall` из другого контура) | ✅ `openwrt-4` в `g1/e1`, ссылка среды из `rotations/` применена, служба запущена |
| Повторное использование | ✅ «invite was already used» |
| Отзыв | ✅ «invite was revoked» |
| Неверный пароль контура | ✅ не пускает (повтор ввода, до 5 раз) |
| Чужой секрет / истёкшая ссылка | ✅ «secret does not match» / «expired» |
| Два одновременных присоединения по одной ссылке | ✅ один «CLAIMED», второй «already used» |
| `uninstall` | ✅ файлы, служба, строки sysupgrade.conf удалены; роутер снят из `contour.json`, его `routers/<id>.json` удалён; секция podkop и ссылка не тронуты |

## Ревью и исправления
| # | Замечание | Сделано |
| --- | --- | --- |
| 1 | ссылка «сгорала», если регистрация не удалась / среда удалена | цель проверяется до регистрации; при сбое захват возвращается (`release`); регистрация в удалённую среду — отказ |
| 2 | прерванный мастер нельзя продолжить | флаг `setup_done`; повторный запуск продолжает с токена/секции/ссылки |
| 3 | код в argv/истории | `--join -` читает код с терминала; подсказка очистить историю (форма из ТЗ сохранена) |
| 4 | состояние приглашения раскрывалось до проверки секрета | секрет проверяется первым |
| 6 | CLI: одиночный, даты | `invite create standalone`, даты |
| 7 | приглашения копятся | удаление использованных/истёкших старше 30 дней |
| 8 | `opkg remove` без выхода из контура; нет предупреждения «последний роутер с токеном» | `prerm` → `peers-ss uninstall --from-opkg` (не при обновлении); предупреждение |
| 5 | офлайн-подбор пароля по коду (токен GitHub даёт чтение шифра) | ограничение: 100k SHA-256 + пароль ≥ 8; рекомендация — длинная фраза (в отчёте/README) |
