# Доработка LuCI (v1.1.0): скорость, три вкладки, перенос перетаскиванием

Запрос владельца: интерфейс открывался почти минуту; объединить вкладки в три; проработать логику, дизайн, простоту; перенос роутеров.

## Скорость
- **Было:** каждая страница при открытии делала из rpcd десятки последовательных запросов к GitHub (каждый роутер, карточка, алерт,
  приглашение — отдельно, 0,5–2 с каждый) → до минуты.
- **Стало:** служба на каждой проверке пишет снимок `/tmp/peers-ss/ui.json` (контур, роутеры, ротации всех привязок без ссылок, карточки,
  алерты, приглашения); rpcd `ui` отдаёт его одним вызовом. Каталоги хранилища читаются одним запросом (ETag), файлы — только при смене `sha`
  (кэш в памяти). Правки из LuCI сразу вносятся в снимок; приглашения/алерты помечают снимок «устаревшим» — служба перечитывает их.
  Снимок никогда не откатывает более новую ревизию контура.
- **Замеры:** `ubus call luci.peers-ss ui` — 0,00–0,07 с на r1/r2/r3; открытие вкладок в браузере — **69–160 мс** (было ~60 с).

## Три вкладки
| Вкладка | Что внутри |
| --- | --- |
| **Обзор** | карточка состояния (статус, конфиг, локация и сервер, срок с «осталось N дн», пинг, последняя ротация, токен; «Проверить сейчас», «Сменить сервер»), предупреждения (ожидание, podkop, GitHub, служба не обновляет данные), роутеры контура, события; сворачиваемые «Настройки контура», «Уведомления (бот)», «Связь и безопасность» (проверка API/GitHub, смена пароля) |
| **Роутеры** | группы карточками, среды плитками (конфиг · локация · сервер · срок, роутеры-«фишки» со статусом и 🔑), **перенос перетаскиванием** в другую среду / «＋ новая среда» / «Одиночные»; меню роутера по клику (то же для телефона: перенести, сделать одиночным, переименовать, убрать); у среды: ⓘ «Состав», 📄 назначить конфиг (архив группы сверху, список через токен любого роутера), ✂ разделить, ＋ пригласить роутер сюда, ✎, 🗑; у группы: объединить среды, ✎, 🗑; приглашения (создать с копированием команды, отозвать, история); архив привязок |
| **Токен и диагностика** | токен (ведущий/ведомый, показать/скрыть, проверить, заменить с предупреждением о ведомых привязках, удалить), 4 слоя проверки ✓/✗, диагностика podkop, пробная ротация, отчёт без секретов, история ротаций, журнал событий по-русски с фильтром и «только ошибки» |

## Логика переноса
- В новую среду роутер уходит **со своим конфигом** (связь не меняется).
- В среду с другим конфигом или без конфига — подтверждение с пояснением, что изменится.
- Чужие/посторонние перетаскиваемые данные игнорируются; во время сохранения страница затемняется, «Сохраняю…».
- Конфликт одновременной правки (другой роутер изменил контур) — сообщение и автоматическая подгрузка актуального состояния.

перенос строк заголовков на узких экранах; защита от пустых ответов.

## v1.2.0 — одна страница, как у podkop
Владелец: «очень долго открывает», ошибка `c.css is not a function`.
- **Причина ошибки:** LuCI загружает JS представлений с `?v=<версия LuCI>`; после обновления Peers-SS браузер держал старый `common.js`
  вместе с новыми вкладками → «Loading view…» навсегда. **Решение:** файлы интерфейса кладутся в папку версии
  `view/peers-ss/<версия>/` (сборка и развёртывание подставляют её в `require` и меню; установщик удаляет старую папку) — смешение
  невозможно.
- **Как podkop:** один пункт меню и одна страница, вкладки переключаются на клиенте (без перезагрузки LuCI), вкладка в `#адресе`,
  общий опрос раз в 20 с; журнал событий подгружается после показа страницы.
- **Замеры на роутере 1 (https, реальное железо):** podkop — 3233 мс холодный / 991 мс повторный; **Peers-SS — 532 / 449 мс**;
  переключение вкладок **43–73 мс**. На VM router3 — страница ~0,3 с, вкладки ~50 мс.
