## Решения / ограничения
- Любой, кто знает **старый** пароль, может пройти по цепочке `rekeys` (смена пароля не отзывает утёкший пароль; отзыв — замена токена GitHub).
- Вкладки, читающие много файлов (Добавить роутер — по файлу на приглашение), грузятся ~10 с на VM; старые приглашения (>30 дней) удаляются.
- LuCI проверялась на VM (у роутера 1 пароль LuCI неизвестен агенту); бэкенд на r1/r2 проверен через ubus/CLI.
