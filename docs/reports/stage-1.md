## Решения агента
- «vless-конфиг» = ссылка `vless://`; `protocol` в API берём из конфига (`vless-2410`).
- Флаги `PATCH` выводим из параметров ссылки; прочие — известное ограничение API.
- Пинг локаций по `host` из `ping_ip`, fallback — время TCP-соединения через `curl -w %{time_connect}`.
