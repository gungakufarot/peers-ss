# AGENTS.md — правила для агентов (Claude Code / OpenCode)

ТЗ: [docs/SPEC.md](docs/SPEC.md). Текущее состояние работ: [docs/PROGRESS.md](docs/PROGRESS.md). Отчёты этапов: `docs/reports/`.

## Порядок работы
- Идти этапами раздела 11 ТЗ; не начинать следующий этап, пока проверка текущего не прошла на тестовом роутере.
- После каждого этапа: ревью отдельным субагентом с чистым контекстом → исправления → повтор проверок → `docs/reports/stage-N.md` → обновить `docs/PROGRESS.md`.

## Правила (раздел 11 ТЗ + владелец проекта)
- Работать только на тестовых роутерах. `PATCH` к StealthSurf — только для конфига `Test-conf`
  (в тестовом режиме включена настройка `test_patch_allow`; в релизе её нет).
- Перед первым изменением — копия `/etc/config/podkop`. В podkop не трогать ничего, кроме управляемой секции и её строки прокси.
  Секцию podkop `KCA` не трогать вообще.
- Не печатать токены, пароль контура и ссылки `vless://` в логи, вывод команд и коммиты.
- Не перезагружать роутер и не обновлять прошивку или podkop без вопроса.
- Не выдумывать поля API и опции podkop: сверяться с https://docs.stealthsurf.net/api, реальными ответами и кодом установленного podkop.
- Секреты лежат вне репозитория (`/root/peers-ss-secrets*.env`). Перед каждым коммитом — `git status` и проверка, что секретов в коммите нет.
- Сервер бота: не трогать ничего, кроме своей службы `peers-ss-bot` и папок `/opt/peers-ss-bot`, `/etc/peers-ss-bot`.
- Spaceship MCP не использовать. telegram-mcp — только переписка с тестовым ботом.
